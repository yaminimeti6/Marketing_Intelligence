# AI Images

Verification: production build, TypeScript and all 98 unit/database tests passed. Authenticated browser tests used a mocked image response to verify preview, JPEG download, visible errors and no overflow at 375/768/1440 pixels, with no page errors. An actual cross-origin endpoint request returned 403. No paid image generation was attempted; provider credits/model access and real output quality remain unverified.

`/ai-images` lets owners/admins request one square, low-quality JPEG concept and download it. Existing `OPENAI_API_KEY` is used server-side. Optional `OPENAI_IMAGE_MODEL` defaults to `gpt-image-1-mini`; supported alternatives are `gpt-image-1` and `gpt-image-1.5`. Paid credits and model access are required. No paid requests were made during implementation verification.

The fixed OpenAI Images endpoint receives only the user's brief (10–1,000 characters) with a product-claim instruction prefix. No imported business records or customer data are attached. The endpoint uses one 1024-square image, JPEG compression 80, a 45-second provider timeout and no automatic retry. Endpoint duration is 60 seconds, but hosting plan limits can still interrupt long calls. Network timeouts do not establish that the provider did not charge usage. `store:false` is not an Images endpoint parameter; provider data controls apply.

Same-origin validation and session/owner-admin authorization precede generation. Database audit reservations enforce at most two image attempts per workspace per rolling hour and ten total AI attempts (text plus images). Failed attempts count. These request caps are not monetary spending caps. No prompt or generated bytes are persisted in audit events.

Provider response JSON is bounded to 4 MB, decoded JPEG to 2 MB, with base64 validation and JPEG signature checks. External image URLs are not followed. The response is private/no-store binary JPEG, avoiding large Server Action serialized payloads. Browser object URLs are revoked when replaced or the page closes. Preview/download is local to the page until you explicitly choose Save to Creative Library. That action stores a normalized WebP asset in the workspace library; the original JPEG remains downloadable here. Ad publishing is not implemented. Verify generated product/label accuracy before use.

Video remains unavailable: OpenAI's Videos API and Sora 2 were removed on 24 September 2026; the user chose image-only implementation rather than configuring another video provider.

Official references: [Images API](https://developers.openai.com/api/reference/typescript/resources/images/methods/generate), [OpenAI deprecations](https://developers.openai.com/api/docs/deprecations).
