# Custom Dashboard

Open `/custom-dashboard`. The starter layout is unsaved. Owners/admins can name and save up to 10 workspace dashboards, update a saved layout, or save it as a new dashboard. Other members can open and view saved layouts. No example dashboards or fabricated metrics are inserted.

Choose widgets for Meta ad spend, attributed revenue, purchase conversions, ROAS, Shopify Net Sales, blended MER, daily Meta spend trend and the top five Meta campaigns by spend. Add/remove widgets, move them with Up/Down buttons and select full-row width. Desktop layout supports two or three columns; mobile uses one. At least one widget is required. Layout edits preview immediately; save/reload applies source and period changes. The data scope above the widgets always describes the loaded figures.

Saved settings include an ordered widget list, widths, layout columns, rolling 7/28 completed days, Meta currency/timezone and account, and Shopify store. Report dates use the selected Meta scope timezone; without one, the selected store timezone is used. Values retain source currency/timezone labels. There is no FX conversion or addition of Meta attributed revenue to Shopify revenue. Saved automatic selections can change as source availability changes; explicit selections preserve source IDs and become unavailable if access is removed.

Widgets reuse covered imported reports. Meta cards, trends and tables require a completed import within 15 minutes. Shopify Net Sales needs a fresh dense event-date report covering the selected days. Missing metrics stay unavailable. MER additionally requires matching currencies/timezones, full account selection and confirmation of all paid channels. Only Meta is currently supported as a paid channel. The chart converts amounts to numbers for plotting; the expandable data table retains exact decimal strings.

Layouts contain registry identifiers, not executable formulas, HTML or database queries. Tenant RLS isolates configurations. Saves check current source access and use revision numbers to reject concurrent overwrite. Updated-by/time and audit events identify changes. This feature reads imported data, and does not start imports, schedule reports or send emails. Scheduled Reports is a separate page. No public dashboard sharing, scheduled dashboard exports, custom formula editor or drag-and-drop interaction is included.
